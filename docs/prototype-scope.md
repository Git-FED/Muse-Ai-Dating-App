# Prototype scope

This repository is a wrapper app, not a complete dating service. The live Muse space supplies the current front-end experience. The wrapper itself only provides a native Android shell and an Electron desktop shell.

The project should not claim that it provides verified users, real matches, a production integration, or a secure dating marketplace. Any demo profiles, fit scores, and date plans should remain clearly labeled as prototype/demo content until a real service, consent flow, moderation system, and privacy review exist.
